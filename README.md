# python3-luanti
_python3-luanti_ is a simple Python3 module to interact with Luanti clients.

**This is not made, sponsored, or endorsed by the Luanti team. This is a separate project, with no intention of recreating or otherwise copying Luanti. However, this project interfaces with and thus requires Luanti. You can find Luanti at the following URL: [https://www.luanti.org/](https://www.luanti.org/), or on their GitHub, which is linked on their website. Once again, this is not made, sponsored, or endorsed by any person or people on the Luanti team.**

## Dependencies
|Dependency|Website|
|---|---|
|Luanti >= 5.0.0|[https://www.luanti.org/](https://www.luanti.org/)|
|python3 >= 3.6|[https://www.python.org/](https://www.python.org/)|
|requests >= 1.0.0|[https://pypi.org/project/requests/](https://pypi.org/project/requests/)|
